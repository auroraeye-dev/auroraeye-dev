# Setup

## 1. Put it in the right repo

A profile README only shows on your GitHub profile if it lives in a repo named
**exactly** after your username:

```
github.com/auroraeye-dev/auroraeye-dev
```

Create that repo (public, with any initial commit), then drop these files in:

```
README.md
SETUP.md
gen_hero.py
gen_about.py
gen_ascii.py
assets/hero.svg
assets/about.svg
assets/_ascii_rows.json
.github/workflows/snake.yml
```

```bash
git add . && git commit -m "feat: animated profile README" && git push
```

## 2. Turn on the snake

The contribution snake is generated by a GitHub Action, not committed by hand.

1. Push the repo (the workflow runs on push to `main`).
2. Repo **Settings → Actions → General → Workflow permissions** → set
   **Read and write permissions**, save.
3. **Actions** tab → *Generate contribution snake* → **Run workflow**.

It writes `snake.svg` / `snake-dark.svg` to an `output` branch, which is what
the README links to. The snake section will show a broken image until that first
run finishes — that's expected.

## 3. Fill in the two placeholders

In `README.md`:

- the LinkedIn badge URL is `https://www.linkedin.com/in/` — add your handle
- `location` in the hero says just `India` — set your city if you want

## 4. Editing the cards

Both SVGs are generated, so edit the `CONFIG` block at the top of the script
rather than hand-patching the SVG:

```bash
python3 gen_hero.py     # name, roles, meta rows, skill chips, socials
python3 gen_about.py    # heading, paragraphs, the shipped.log grid
```

`gen_ascii.py` regenerates the dithered portrait in the left panel
(`assets/_ascii_rows.json`). Change the seed at the top for a different dither,
or replace the JSON with your own array of ASCII rows — one string per line,
46 columns wide — if you'd rather use a real photo converted to ASCII.

Re-run `gen_hero.py` after touching the ASCII so the new rows get baked in.

## Notes

- The animation is pure CSS inside the SVG — no JavaScript, no external fonts,
  no network calls. GitHub serves it through its image proxy and it still runs.
- Everything under *By the numbers* is a third-party service
  (`github-readme-stats`, `streak-stats`, `github-readme-activity-graph`).
  They're free and widely used, but they're not yours — if one goes down or
  gets rate-limited, that card shows as broken. Delete the line if that bugs you.
- The hero renders at 1000×512 and scales to the README column width.
